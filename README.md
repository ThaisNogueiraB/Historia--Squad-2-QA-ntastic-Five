# 📝 Atividade de Versionamento com Git

## 📌 Descrição da Atividade

Nesta atividade em Squad, o objetivo é aplicar na prática os conhecimentos adquiridos sobre **Git**, **branches**, **merge** e **boas práticas de versionamento**. A dinâmica será colaborativa e todos os membros da Squad deverão contribuir com uma parte de um único documento.
- A Squad criará um **repositório compartilhado** no GitHub.
- Um documento `.txt` será criado com o início de uma **história fictícia**.
- Cada integrante da Squad irá contribuir com uma parte dessa história, utilizando **branches individuais**.
- Ao final, todos deverão realizar o **merge do conteúdo para a branch `main`**, garantindo que a história completa esteja consolidada.

---

## 🎯 Objetivos

- Exercitar o uso de **branches** e **merges** no Git.
- Praticar **versionamento colaborativo** em um mesmo arquivo.
- Simular um fluxo real de desenvolvimento.
- Reforçar o uso de **boas práticas de controle de versão** em equipe.

---

## 📝 Entregável

- Repositório GitHub criado e compartilhado entre os membros da Squad.
- Documento `.txt` com a história final mesclada na branch `main`.
- Histórico de merges realizado corretamente nas branches individuais e na `main`.
